# Tech & Code Summit 2026

Portal oficial do evento Tech & Code Summit, desenvolvido como projeto acadêmico para o terceiro semestre do curso de desenvolvimento de software multiplataforma. A aplicação utiliza uma arquitetura baseada em uma API REST com Node.js e Express no backend, e uma interface frontend consumindo os dados de forma dinâmica através do `fetch`.

## 🚀 Tecnologias Utilizadas

**Backend:**
* [Node.js](https://nodejs.org/) - Ambiente de execução JavaScript.
* [Express](https://expressjs.com/) - Framework web para a criação das rotas da API.
* Módulo `fs` (File System) - Leitura e gravação persistente dos dados no arquivo JSON.

**Frontend:**
* HTML5 simples estruturando múltiplas páginas.
* CSS3 moderno utilizando variáveis globais (`:root`), Flexbox e CSS Grid para o layout responsivo.
* JavaScript (Vanilla JS) utilizando a [Fetch API](https://developer.mozilla.org/pt-BR/docs/Web/API/Fetch_API) para renderização dinâmica no lado do cliente.
